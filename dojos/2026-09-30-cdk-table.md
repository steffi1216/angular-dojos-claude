# Angular Dojo: CdkTable – Barrierefreie Tabellen mit Angular CDK
**Datum:** 2026-09-30
**Dauer:** ~25 Minuten
**Level:** Fortgeschritten

## Lernziel
Du lernst, mit `CdkTable` aus `@angular/cdk/table` eine vollständig unstyled, zugängliche Tabelle mit eigenem `DataSource`-Pattern zu bauen – und verstehst, warum das eine bessere Basis als `<table>` mit `*ngFor` ist.

## Hintergrund & Theorie

`CdkTable` ist die unstyled Grundlage von Angular Materials `MatTable`. Sie trennt konsequent drei Belange:

**DataSource** ist eine abstrakte Klasse (oder ein Observable), die der Tabelle sagt, *welche Daten* angezeigt werden. Eine `DataSource` implementiert `connect()` (gibt `Observable<T[]>`) und `disconnect()`. Dadurch kann die Tabelle Sortierung, Paginierung und Filterung delegieren, ohne selbst Datenhaltung zu betreiben.

**Column Definitions** (`cdkColumnDef`) bündeln Header-Cell und Data-Cell in einem wiederverwendbaren Template. Jede Spalte hat einen eindeutigen Namen und definiert über `cdkHeaderCellDef` und `cdkCellDef` ihre Templates unabhängig voneinander.

**Row Definitions** (`cdkHeaderRowDef`, `cdkRowDef`) steuern, welche Spalten in welcher Reihenfolge gerendert werden – als einfaches String-Array `[columns]`. Das erlaubt zur Laufzeit dynamisch Spalten ein- und auszublenden.

Die Tabelle rendert entweder als natives `<table>` (für `mat-table`-Style und Barrierefreiheit) oder als Flex-Layout (`CdkTableModule` mit `[cdkTable]`-Attribut auf einem `<div>`). Das ARIA-`role="grid"` wird automatisch gesetzt.

Ein wichtiger Vorteil gegenüber `*ngFor`: `CdkTable` nutzt intern `EmbeddedView`-Recycling ähnlich wie Virtual Scrolling – Zeilen werden nur bei tatsächlicher Änderung neu gerendert.

## Aufgabe

Baue eine wiederverwendbare `<app-data-table>`-Komponente, die:
1. Eine typisierte `DataSource` mit Observable-Backend nutzt
2. Dynamisch konfigurierbare Spalten unterstützt (via Input)
3. Klick-Selektion einer Zeile hervorhebt
4. Ladeindikator zeigt, solange Daten geladen werden

### Schritte

1. **Setup:** Importiere `CdkTableModule` in deiner Standalone-Komponente. Definiere ein `User`-Interface `{ id: number; name: string; email: string; role: string }`.

2. **DataSource erstellen:** Implementiere `UserDataSource extends DataSource<User>`. Die `connect()`-Methode gibt ein `BehaviorSubject<User[]>` zurück. Füge eine `setLoading()`-Methode hinzu, die über einen separaten `BehaviorSubject<boolean>` den Ladezustand kommuniziert.

3. **Komponente aufbauen:** Erstelle `DataTableComponent` mit folgenden Inputs:
   - `dataSource: DataSource<T>` 
   - `columns: string[]` (Reihenfolge der anzuzeigenden Spalten)
   - `displayedColumns` wird intern aus `columns` berechnet (Signal oder Getter)
   Verwende `<table cdk-table>` mit `cdkColumnDef` für `id`, `name`, `email` und `role`.

4. **Selektion:** Füge eine `selectedRow = signal<User | null>(null)` hinzu. Wende eine CSS-Klasse `selected` per `[class.selected]`-Binding auf `<tr cdk-row>` an.

5. **Integration:** Verwende die Komponente in `AppComponent`, lade Daten nach 1,5 Sekunden (simulierter API-Call via `timer(1500)`) und zeige in der Zwischenzeit einen Spinner-Platzhalter.

## Hints

<details>
<summary>Hint 1 – DataSource-Grundgerüst</summary>

```typescript
import { DataSource } from '@angular/cdk/collections';
import { BehaviorSubject, Observable } from 'rxjs';

export class UserDataSource extends DataSource<User> {
  private _data = new BehaviorSubject<User[]>([]);
  loading$ = new BehaviorSubject<boolean>(true);

  setData(users: User[]) {
    this._data.next(users);
    this.loading$.next(false);
  }

  connect(): Observable<User[]> {
    return this._data.asObservable();
  }

  disconnect() {
    this._data.complete();
    this.loading$.complete();
  }
}
```

</details>

<details>
<summary>Hint 2 – CdkTable Template-Grundstruktur</summary>

```html
<table cdk-table [dataSource]="dataSource">
  <!-- Column Definition -->
  <ng-container cdkColumnDef="name">
    <th cdk-header-cell *cdkHeaderCellDef>Name</th>
    <td cdk-cell *cdkCellDef="let row">{{ row.name }}</td>
  </ng-container>

  <!-- Header Row -->
  <tr cdk-header-row *cdkHeaderRowDef="displayedColumns"></tr>

  <!-- Data Rows -->
  <tr
    cdk-row
    *cdkRowDef="let row; columns: displayedColumns"
    [class.selected]="selectedRow() === row"
    (click)="selectedRow.set(row)"
  ></tr>
</table>
```

</details>

## Beispiellösung

```typescript
// user.model.ts
export interface User {
  id: number;
  name: string;
  email: string;
  role: string;
}

// user-data-source.ts
import { DataSource } from '@angular/cdk/collections';
import { BehaviorSubject, Observable } from 'rxjs';
import { User } from './user.model';

export class UserDataSource extends DataSource<User> {
  private _data = new BehaviorSubject<User[]>([]);
  readonly loading$ = new BehaviorSubject<boolean>(true);

  setData(users: User[]): void {
    this._data.next(users);
    this.loading$.next(false);
  }

  connect(): Observable<User[]> {
    return this._data.asObservable();
  }

  disconnect(): void {
    this._data.complete();
    this.loading$.complete();
  }
}

// data-table.component.ts
import { Component, computed, input, signal } from '@angular/core';
import { CdkTableModule } from '@angular/cdk/table';
import { DataSource } from '@angular/cdk/collections';
import { User } from './user.model';

@Component({
  selector: 'app-data-table',
  standalone: true,
  imports: [CdkTableModule],
  template: `
    <table cdk-table [dataSource]="dataSource()">
      <ng-container cdkColumnDef="id">
        <th cdk-header-cell *cdkHeaderCellDef>#</th>
        <td cdk-cell *cdkCellDef="let row">{{ row.id }}</td>
      </ng-container>

      <ng-container cdkColumnDef="name">
        <th cdk-header-cell *cdkHeaderCellDef>Name</th>
        <td cdk-cell *cdkCellDef="let row">{{ row.name }}</td>
      </ng-container>

      <ng-container cdkColumnDef="email">
        <th cdk-header-cell *cdkHeaderCellDef>E-Mail</th>
        <td cdk-cell *cdkCellDef="let row">{{ row.email }}</td>
      </ng-container>

      <ng-container cdkColumnDef="role">
        <th cdk-header-cell *cdkHeaderCellDef>Rolle</th>
        <td cdk-cell *cdkCellDef="let row">{{ row.role }}</td>
      </ng-container>

      <tr cdk-header-row *cdkHeaderRowDef="displayedColumns()"></tr>
      <tr
        cdk-row
        *cdkRowDef="let row; columns: displayedColumns()"
        [class.selected]="selectedRow() === row"
        (click)="selectedRow.set(row)"
      ></tr>
    </table>
  `,
  styles: [`
    table { width: 100%; border-collapse: collapse; }
    th, td { padding: 8px 12px; border: 1px solid #ddd; text-align: left; }
    th { background: #f5f5f5; font-weight: 600; }
    tr.selected td { background: #e3f2fd; }
    tr:hover td { background: #fafafa; }
    tr.selected:hover td { background: #bbdefb; }
  `]
})
export class DataTableComponent {
  dataSource = input.required<DataSource<User>>();
  columns = input<string[]>(['id', 'name', 'email', 'role']);
  selectedRow = signal<User | null>(null);

  displayedColumns = computed(() => this.columns());
}

// app.component.ts
import { Component, OnInit } from '@angular/core';
import { timer } from 'rxjs';
import { AsyncPipe } from '@angular/common';
import { DataTableComponent } from './data-table.component';
import { UserDataSource } from './user-data-source';
import { User } from './user.model';

const MOCK_USERS: User[] = [
  { id: 1, name: 'Alice Müller', email: 'alice@example.com', role: 'Admin' },
  { id: 2, name: 'Bob Schmidt', email: 'bob@example.com', role: 'Editor' },
  { id: 3, name: 'Clara Wagner', email: 'clara@example.com', role: 'Viewer' },
];

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [DataTableComponent, AsyncPipe],
  template: `
    @if (dataSource.loading$ | async) {
      <p>⏳ Daten werden geladen…</p>
    } @else {
      <app-data-table
        [dataSource]="dataSource"
        [columns]="['name', 'email', 'role']"
      />
    }
  `
})
export class AppComponent implements OnInit {
  dataSource = new UserDataSource();

  ngOnInit(): void {
    timer(1500).subscribe(() => this.dataSource.setData(MOCK_USERS));
  }
}
```

## Weiterführendes

- **Sortierung** mit `MatSort` oder eigenem `sort`-Operator: Die `DataSource` kann `CollectionViewer` und ein `Sort`-Observable kombinieren, um gefilterte/sortierte Daten zurückzugeben – schau dir `MatTableDataSource` als Referenzimplementierung an.
- **Virtuelle Zeilen** mit `CdkVirtualScrollViewport` + `CdkTable`: Kombiniere beide CDK-Module für Tabellen mit zehntausenden Zeilen ohne Performance-Einbußen.
- [Angular CDK Table Docs](https://material.angular.io/cdk/table/overview)
